# Проверка MAGLUMI X8, 26.10.2026

- Сборка `AnalyzerService.sln`: успешно, ошибок компиляции нет.
- `Maglumi.Snibe.Driver.Tests`: **85 проверок пройдено**. Проверены MLLP/UTF-8, фрагментация, несколько сообщений, ограничения кадров, задания и пустые ответы, ошибка БД, поля пациента, сопоставления кодов, точность чисел, статусы/флаги/тревоги, выходные файлы, повторная обработка, восстановление очереди, QC, переподключение, остановка и отмена.
- `VerifySharedComponents.ps1`: **29 файлов** пяти общих компонентов совпадают по SHA-256 с исходным Sysmex и сохранённым манифестом.
- Публикация `win-x64`, framework-dependent, Host одним файлом: успешно. Каталог драйвера содержит собственную DLL и `.deps.json`.
- `PublishedPackageSmoke.ps1`: опубликованный Host загрузил DLL, открыл TCP listener и сохранил точные байты пациентского/QC сообщений; лишних ACK нет. Рабочая конфигурация не использовалась.

В общем `AnalyzerRuntime.cs` сохранены два исходных предупреждения CS8602; файл не изменялся. При восстановлении тестовых зависимостей возникало NU1900 из-за недоступности NuGet vulnerability feed. Недостающие зависимости публикации восстановлены с сетевым доступом; предупреждение об аудите не является результатом проверки безопасности пакетов.

Проверки SQL-логики выполнялись с подставными ответами на границе самой DLL. Общий `LisDBProvider` не изменён. Рабочая БД ЛИС и реальный анализатор не подключались. До внедрения требуется заполнить конфигурацию, проверить соответствия тестов, реальный приоритет TSREQ, приём пустого SPM-4 и файловый импорт на стенде.
